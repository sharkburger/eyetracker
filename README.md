# 眼动仪图鉴 · Eye Tracker Atlas

中文眼动设备公开资料综述，收录 **50 款设备与产品系列、27 个品牌、7 类用途**。每条附介绍、场景、编辑评述、规格条件、产品图片及原始来源。

**网站：https://sharkburger.github.io/eyetracker/**

## 阅读与功能

- 按类别、品牌、资料状态筛选；全文搜索；按名称或所列频率排序。
- 设备档案展示完整评述、规格模式、图片署名与官方原文。
- 选择 2–4 款设备进行并排比较；详情支持 `#device=neon` 形式链接。
- 下载 `devices.json` 或 UTF-8 BOM 编码的 `devices.csv`。
- 适配手机与桌面；设备基础简介与原链接在关闭 JavaScript 时仍可阅读。

## 内容方法与范围

资料核查日期：**2026-10-15**。以厂商产品页、官方手册、开发文档和停产说明为主要依据；部分旧型号或受访问限制的设备注明需进一步确认。综述为公开资料整理，未进行统一条件的实机横向测试，不给出伪实测评分。

此处的 50 条包含产品系列，不等于 50 个独立硬件 SKU，也不代表全球所有型号。桌面科研、可穿戴、VR/XR、辅助沟通、消费交互、专用集成、历史型号均有覆盖。未穷尽历史 SMI / Eye Tribe 全系列、地区性厂商、OEM 定制模块、临床前庭/眼震仪器、搜索线圈与 EOG 系统。网络摄像头软件平台未计作硬件。

`hz` 仅用于展示已核实的最高值或所列运行模式，必须同时阅读 `specNote`，不能当成所有模式的固定频率。留空表示本版不作数值主张。不同设备准确度的测试条件不一致，因此未设简单精度排行榜。官网留有资料不证明当前在售或仍获维护。

## 文件与维护

- `index.html`：预渲染目录及内嵌数据，保证无需后台即可访问。
- `app.js`、`style.css`：筛选、对比、详情与样式。
- `devices.json`、`devices.csv`：完整可下载资料。
- `assets/`：优化后的产品照片、官方图示及少量明确注明的宣传图。
- `CREDITS.md`：逐条图片原链接、来源页面和署名。

更新设备资料时应同步修改 `devices.json`、`devices.csv` 及 `index.html` 内的 `dataset` 与预渲染卡片。所有资料字段均使用 UTF-8。网站无需构建工具、第三方 CDN 或运行时依赖。可直接由 GitHub Pages 从 `main` 分支仓库根目录发布。`.nojekyll` 禁用 Jekyll 转换。

## 图片与资料权利

图片和商标归各原权利人，未将第三方图片声明为开放许可。保留原图与出处用于设备识别与资料追溯。图片仅作资料综述展示；如权利人希望调整署名或移除图片，可通过 Issues 联系。编辑文字和网站代码与图片权利分开处理。
