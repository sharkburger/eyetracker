从记录眼睛，
到理解与交互。

01 / 1898–1948

把眼动变成记录

从眼部接触到摄影与早期头戴装置，首先解决的是“如何留下记录”。

1898–1908研究时期 / 1908 专著
测量方法#01

让眼球运动留下物理轨迹

Huey 的早期阅读研究使用与眼部接触的记录装置，1908 年专著系统整理了相关方法。这一时期，人们尝试把短暂的眼球运动变成可检查的记录。

这一步改变了什么从主观观察走向仪器记录。
限制与阅读提示

接触眼部的装置影响舒适性，也会限制自然观看。

[01] 原始专著 ↗
1901论文 / 专著发表
测量方法#02

用光学摄影记录眼动

Dodge 与 Cline 发表眼球运动角速度研究，使用摄影记录路线，使测量不必依赖眼部的机械连接。

这一步改变了什么光学记录成为重要的非接触测量方向。
限制与阅读提示

早期装置仍依赖受控姿态，记录维度和后续分析受到限制。

[02] 原始论文 ↗
1935论文 / 专著发表
认知研究#03

从阅读扩展到看图

Buswell 在《How People Look at Pictures》中研究观看艺术作品时的注视分布与路径。眼动记录开始帮助比较不同观看者如何探索复杂图像。

这一步改变了什么研究问题扩展到图像知觉和视觉探索。
限制与阅读提示

记录路径不等于直接读出注意、理解或观看意图。

[03] 原始专著 ↗
1948论文 / 专著发表
测量方法#04

记录装置开始跟随头部

Hartridge 与 Thomson 发表眼动调查方法，展示把记录装置与头部关联的早期技术路线，为后来头戴式追踪的发展提供了基础。

这一步改变了什么不再只考虑把被试固定在外部仪器前。
限制与阅读提示

早期头戴结构仍有体积、固定方式和活动范围的限制。

[04] 原始论文 ↗
02 / 1963–1973

精密测量与视觉科学

磁场线圈与高精度光学并行发展，经典视觉实验也让研究者更关注任务与观看之间的联系。

1963论文 / 专著发表
测量方法#05

搜索线圈：从磁场测量眼球转动

Robinson 发表巩膜搜索线圈方法：通过眼部线圈在磁场中的感应信号记录眼球运动。这是与相机式追踪不同的测量分支。

这一步改变了什么为精密眼球运动研究提供了重要工具。
限制与阅读提示

需要专门磁场与眼部接触装置；不能理解成普通无接触桌面眼动仪。

[05] 原始论文 ↗
1965 / 1967俄文 / 英文版
认知研究#06

同一画面，不同任务，不同视线

Yarbus 的专著于 1965 年出版俄文版，1967 年出版英文版。其任务指令实验使眼动与观看目的之间的关系成为经典研究问题。

这一步改变了什么记录眼睛去了哪里，也开始追问为什么这样看。
限制与阅读提示

经典示例不能证明仅凭一条视线轨迹就能可靠识别一个人的思想。

[06] 原始专著 ↗[07] 历史研究 ↗
1973论文 / 专著发表
测量方法#07

双 Purkinje 图像：更精细的光学追踪

Cornsweet 与 Crane 描述利用第一、第四 Purkinje 图像的二维眼动仪，在红外下测量眼球运动，且不需要把装置附着在眼球上。

这一步改变了什么高精度光学测量与减少眼部接触可以同时推进。
限制与阅读提示

复杂光学结构和工作范围仍会约束实验布置；不是所有红外设备都属于双 Purkinje 系统。

[08] 原始论文 ↗
03 / 1980–1990

从理解认知到眼控输入

眼动既可以检验认知理论，也可以让使用者操作电脑，研究问题开始分化。

1980论文 / 专著发表
认知研究#08

眼动成为检验阅读认知理论的工具

Just 与 Carpenter 的阅读理论论文把眼睛的注视行为与理解过程联系起来，体现了眼动指标在认知研究中的作用。

这一步改变了什么硬件输出成为可以与认知理论对照的时间序列。
限制与阅读提示

注视时长需要结合任务与理论解释，并不是某个心理过程的唯一标签。

[09] 原始论文 ↗
1989论文 / 专著发表
交互与辅助访问#09

眼睛也可以成为电脑输入

Hutchinson 等人介绍 Erica 工作站，以眼睛图像估计屏幕凝视位置，并通过菜单选择操作电脑；论文也讨论其辅助技术应用。

这一步改变了什么眼动从观察工具延伸为访问和沟通通道。
限制与阅读提示

可用性取决于选择机制、误触、校准与持续使用体验，而不仅是采样频率。

[10] 原始论文 ↗
1990论文 / 专著发表
交互与辅助访问#10

如何区分“看”与“想要操作”

Jacob 在 CHI 1990 讨论基于眼动的人机交互技术。研究焦点逐渐从能否测量凝视，转向如何把自然观看变成可靠输入。

这一步改变了什么交互设计成为与传感器同样重要的问题。
限制与阅读提示

用户看向一个对象，并不自动代表想要激活它；仍需设计确认与反馈。

04 / 2001–2016

更易部署、更开放、更多数据

商业产品、开源工具和学习式算法分别降低了不同的使用门槛。

2001 / 2002成立 / 产品节点
研究平台#11

远程眼动走向更易部署的产品

Tobii 的公司史记录了 2001 年成立、2002 年推出眼动产品的过程。这是屏幕式研究工具降低部署门槛的一个代表性商业节点。

这一步改变了什么校准、采集与分析开始形成更完整的产品工作流。
限制与阅读提示

这是特定厂商的节点，不是全球所有商业眼动仪的起点。

2014论文 / 专著发表
研究平台#12

开源可穿戴平台推动定制研究

Kassner、Patera 与 Bulling 发表 Pupil 平台论文，将可穿戴相机、开源软件和回放可视化结合，强调可扩展与可定制。

这一步改变了什么研究者可以更直接地修改采集和处理流程。
限制与阅读提示

开放软件不等于完全没有硬件、校准或维护成本；论文原型参数也不能套用到后来所有型号。

[13] 原始论文 ↗
2016论文 / 专著发表
研究平台#13

普通摄像头与数据驱动凝视估计

GazeCapture / iTracker 研究使用手机和平板数据训练神经网络，探索不增加专用传感器的凝视估计。它代表软件化与规模化的一条重要路线。

这一步改变了什么扩大了可使用的硬件与参与人群范围。
限制与阅读提示

软件估计与专用仪器的输出单位、误差与测试条件不同，不能直接等同于科研级硬件表现。

05 / 2019–2021

走进真实场景与可穿戴设备

自然佩戴、空间输入和新的传感架构，让眼动逐渐离开固定的实验台。

2019厂商发布 / 交付
研究平台#14

深度学习走进日常外形的眼镜

Pupil Labs 在 2019 年推出 Pupil Invisible，将学习式凝视估计带入更接近日常眼镜的形态，并弱化传统逐人校准流程。

这一步改变了什么自然佩戴和准备时间成为重要的产品设计目标。
限制与阅读提示

免校准不等于零误差，仍需针对任务、光线和人群验证数据质量。

2019厂商发布 / 交付
交互与辅助访问#15

眼动成为透视式 AR 的空间输入

HoloLens 2 于 2019 年开始交付，将眼动与手势、空间计算结合。开发者可以在获得权限后使用凝视信息构建交互。

这一步改变了什么凝视从二维屏幕位置扩展到空间中的方向与目标。
限制与阅读提示

标准与扩展接口的数据不同；许可、校准和系统 API 决定实际可用信息。

测量方法#16

MEMS：不依赖眼部成像相机的另一分支

AdHawk 在 2021 年发布 MindLink，以 MEMS 传感路线进行眼动测量，展示了传统视频式方案之外的可穿戴设计选择。

这一步改变了什么小型化与功耗问题可以通过不同传感架构探索。
限制与阅读提示

技术路线不同，也意味着数据定义和验证方式需要重新核对；发布公告不代表当前仍有供货。

眼动进入 XR 系统、游戏内容和多模态研究平台，同时带来接口、隐私与验证的新问题。

XR 设备整合眼动与虚拟化身表达

这一步改变了什么眼动开始作为完整 XR 体验中的一项内置能力。
限制与阅读提示

内置传感器不等于向所有应用开放全部原始信号。

功能取决于应用和运行平台；主机功能不能直接视作开放科研数据接口。

PARALLEL PATHS, NOT A SINGLE LADDER

新路线出现，旧路线并没有消失。

时间线用于理解变化，不用于给仪器排优劣。精密测量、真实场景记录、辅助访问与空间交互各自有不同目标。下面是对前述节点的编辑归纳，而非性能测试结论。

精密测量仍有独立价值

搜索线圈、精密光学和高速视频式设备，服务于不同实验条件。年代更近不自动意味着测量更适合。

自然活动带来新的误差来源

可穿戴与学习式估计降低某些部署门槛，但滑移、环境、人群差异和数据映射仍需要验证。

系统交互与科研访问是两件事

能用眼睛操作设备，不代表应用能导出连续原始数据。研究采购仍要逐项核对 API、授权和同步。

METHOD & ORIGINAL SOURCES

年代有依据，解释有边界。

原始论文、原始专著与同期厂商发布资料优先；必要时补充有明确署名的历史研究和官方文档。阶段划分与“改变了什么”是编辑归纳，不代表学界统一分期。
